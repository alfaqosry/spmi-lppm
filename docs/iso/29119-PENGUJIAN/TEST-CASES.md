# Spesifikasi Kasus Uji (Test Case Specification) — SPMI v1.1.3

Acuan: ISO/IEC/IEEE 29119-3 §8.3. Basis uji: KF/KNF/AB di [01-PERANCANGAN](../../01-PERANCANGAN.md) (+ KNF-13…17
turunan, lihat [TRACEABILITY §1.3](TRACEABILITY.md#13-kebutuhan-turunan-diusulkan)). Kode dalam kurung (L-01, A-05, …)
merujuk checklist UAT [06-PENGUJIAN §4](../../06-PENGUJIAN.md#4-checklist-uat).

## Konvensi

- **ID:** `TC-<MODUL>-nn` — LOG login/SSO/sesi · DSH dashboard · SIK siklus · UNT unit · ROL akun & penempatan ·
  DOK penetapan/evaluasi · AUD audit & verifikasi · ANL analitik & PDF · SET pengaturan · PRV privasi ·
  SEC keamanan/RBAC · NF non-fungsional.
- **Tipe:** `Auto-U` (Vitest) · `Auto-E` (Playwright) · `Auto-CI` (pemeriksaan CI) · `Manual` · `Manual+U` (UI manual, logika inti sudah diuji unit).
- **Rujukan otomatis:** `U:<berkas>` = `tests/unit/<berkas>.test.ts`, `E:<berkas>` = `tests/e2e/<berkas>.spec.ts`;
  nama test ditulis `describe › test` persis seperti di kode (nama ber-parameter `%s`/`%j` mewakili seluruh variasinya).
- **Status (eksekusi v1.1.3, 17 Okt 2026):** ✅ lulus · ⚠️ logika lulus otomatis, UI/integrasi belum dieksekusi manual ·
  ⏳ belum dieksekusi · ❌ gagal · ⛔ diblokir.
- Kasus E2E dijalankan di 5 profil (chromium, firefox, webkit, pixel-7, iphone-14) kecuali disebut lain.
- Prasyarat umum: lingkungan uji ENV-2/ENV-4 ([TEST-PLAN §7](TEST-PLAN.md#7-lingkungan)) dengan seed akun per peran;
  **jangan** mengeksekusi kasus yang mengubah data di produksi.
