# ISO/IEC 27001:2022 — Statement of Applicability (SoA) SPMI

Pernyataan Keberlakuan seluruh **93 kontrol Annex A** ISO/IEC 27001:2022 (rincian penerapan mengacu ISO/IEC 27002:2022)
untuk **Sistem Informasi SPMI — LPM Universitas Pahlawan Tuanku Tambusai**.

| Versi dokumen | Tanggal         | Versi aplikasi | Klasifikasi      | Status                                     |
| ------------- | --------------- | -------------- | ---------------- | ------------------------------------------ |
| 1.0           | 17 Oktober 2026 | v1.1.3         | Dokumen Internal | Draf teknis — ⏳ pengesahan pemilik risiko |

## 1. Ruang Lingkup dan Batasan

- **Dalam lingkup:** aplikasi SPMI (kode di repositori ini), server produksi Windows Server 2025 yang menjalankannya
  (`E:\www\spmi-prod`: IIS ARR, PM2, kontainer MySQL `spmi-db`, berkas unggahan, backup, log), pipeline CI/CD
  (GitHub Actions), konfigurasi Cloudflare untuk host `spmi.universitaspahlawan.ac.id`, dan integrasi SSO UP.
- **Di luar lingkup:** infrastruktur SSO UP, jaringan kampus, perangkat pengguna, sistem universitas lain di server yang sama
  (dikendalikan Puskom/institusi — dicatat sebagai kontrol yang bergantung institusi).
- **Catatan jujur:** universitas **belum** menetapkan ISMS formal (klausul 4–10 ISO/IEC 27001: kebijakan, penilaian risiko
  organisasi, audit internal ISMS, tinjauan manajemen). SoA ini adalah **dasar teknis** yang siap dipakai bila ISMS
  ditetapkan; kontrol yang memerlukan keputusan, SDM, atau fasilitas institusi ditandai ⏳ dan tidak diklaim terpenuhi.
- Penilaian risiko yang menjadi dasar pemilihan kontrol: [RISK-REGISTER.md](RISK-REGISTER.md) dan
  [THREAT-MODEL-STRIDE.md](THREAT-MODEL-STRIDE.md).

**Legenda status:**
✅ **diterapkan** — mekanisme teknis/dokumen ada di repositori atau server dan dapat diverifikasi (catatan sisa pekerjaan
dapat menyertai) · ⏳ **butuh institusi** — memerlukan kebijakan, penunjukan, SDM, kontrak, atau fasilitas di luar kendali
tim pengembang (dukungan teknis yang sudah ada disebutkan) · **N/A** — tidak berlaku, dengan justifikasi & kondisi pemicu.

Temuan penting saat penyusunan (17 Okt 2026, diperiksa langsung di server):

1. **Microsoft Defender real-time protection dalam keadaan nonaktif** (`Get-MpComputerStatus` → `RealTimeProtectionEnabled: False`;
   layanan AM aktif, signature 16 Okt 2026) → A.8.7, risiko R-21.
2. Aturan firewall Windows yang membatasi 80/443 hanya dari rentang IP Cloudflare **tidak ditemukan** dengan nama
   yang jelas → perlu diverifikasi (A.8.20, risiko R-09).
3. Backup berada di server yang sama (E: dan D:), tanpa enkripsi, tanpa salinan luar server → A.8.13/A.5.30, risiko R-05.
4. Image DB `mysql:8.0` sudah melewati EOL (April 2026) → A.8.8, risiko R-24.
