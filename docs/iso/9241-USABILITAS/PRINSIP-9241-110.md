# Pemetaan 7 Prinsip Interaksi ISO 9241-110:2020

Setiap prinsip dipetakan ke **bukti implementasi** di kode v1.1.3, **celah** (merujuk
[EVALUASI-HEURISTIK](EVALUASI-HEURISTIK.md)), dan status. Keterangan: ✅ terpenuhi · ⚠️ sebagian · ❌ belum.

| No  | Prinsip                                      | Status |
| --- | -------------------------------------------- | ------ |
| 1   | Kesesuaian dengan tugas pengguna (TS)        | ⚠️     |
| 2   | Kemampuan menjelaskan diri (SD)              | ⚠️     |
| 3   | Kesesuaian dengan harapan pengguna (CE)      | ✅/⚠️  |
| 4   | Kemudahan dipelajari (LE)                    | ⚠️     |
| 5   | Keterkendalian (CO)                          | ⚠️     |
| 6   | Ketahanan terhadap kesalahan penggunaan (ER) | ⚠️     |
| 7   | Keterlibatan pengguna (UE)                   | ⚠️     |

## 1. Kesesuaian dengan Tugas Pengguna (_Suitability for the user's tasks_)

Sistem mendukung pengguna menyelesaikan tugas secara efektif & efisien, tanpa langkah yang tidak perlu.

| Bukti                                                                                       | Lokasi                                                                 |
| ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Menu difilter per peran — pengguna hanya melihat fungsi yang relevan                        | `src/components/layout/nav-items.ts`, `sidebar.tsx` (`roles.includes`) |
| Auditee hanya melihat pertanyaan yang **berlaku untuk unitnya** (cakupan all/category/unit) | `isQuestionForUnit` — `src/lib/scope.ts`; `AuditeeAuditWorkspace`      |
| Formulir jawaban adaptif: **Ya** memunculkan bukti, **Tidak** memunculkan alasan (AB-06)    | `ResponseForm`                                                         |
| Rangkap jabatan: pemilih unit dalam satu halaman                                            | `AuditeeAuditWorkspace` (`myUnits.length > 1`)                         |
| Penyusunan butir **massal** (daftar sementara → simpan sekaligus)                           | `StandardQuestionsDialog`, `createQuestionsBulk`                       |
| Dashboard berbeda untuk LPM (monitoring) dan auditee (progres unit + unduh PDF unit)        | `src/app/(dashboard)/dashboard/page.tsx`                               |

Celah: HE-08 (simpan per butir tanpa draf), HE-21 (verifikasi tanpa aksi massal), HE-27 (dokumen tidak dapat diubah),
HE-14 (menu placeholder Monev), HE-31.

## 2. Kemampuan Menjelaskan Diri (_Self-descriptiveness_)

Pada setiap saat pengguna tahu di mana ia berada, apa yang dapat dilakukan, dan status sistem.

| Bukti                                                                                                                | Lokasi                                                                       |
| -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Judul halaman + deskripsi konsisten (`PageHeader`), `<title>` per halaman (`%s · SPMI …`)                            | `src/components/ui/primitives.tsx`, metadata tiap `page.tsx`                 |
| Item menu aktif ditandai `aria-current="page"` + penanda visual                                                      | `sidebar.tsx`                                                                |
| Status progres terlihat: "x/y (z%)", badge "Lengkap"/"n tersisa", status butir (Menunggu/Terverifikasi/Perlu Revisi) | `AuditeeAuditWorkspace`, `AspectGroup`, `STATUS_LABEL` (`src/lib/format.ts`) |
| Status siklus: badge Aktif / Lewat Batas / Arsip; banner "Periode pengisian ditutup"                                 | `cycle-manager.tsx`, `audit/page.tsx`, `dashboard/page.tsx`                  |
| Hint format di bawah field ("Format PDF, maksimal 10 MB", kebijakan kata sandi `PASSWORD_POLICY_HINT`)               | `Field` `hint`, `account-manager.tsx`                                        |
| Tanda wajib `*` otomatis dari atribut `required`                                                                     | `Field` (`form.tsx`)                                                         |

Celah: **HE-01** (tenggat tidak tampil), **HE-02** (revisi tersembunyi), HE-06 (status unduhan PDF), HE-19, HE-28.

## 3. Kesesuaian dengan Harapan Pengguna (_Conformity with user expectations_)

Perilaku sistem dapat diprediksi, konsisten, dan sesuai konvensi domain AMI serta platform web.

| Bukti                                                                                          | Lokasi                                                                                  |
| ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Bahasa Indonesia baku, istilah domain AMI (Standar, Butir, RTL, Ketua LPM, Penetapan/Evaluasi) | Seluruh UI; `lang="id"` (`src/app/layout.tsx`)                                          |
| Tanggal `id-ID` zona Asia/Jakarta di semua tampilan                                            | `formatDate`, `formatDateTime` (`src/lib/format.ts`, diuji `tests/unit/format.test.ts`) |
| Kelas tombol baku (`BTN_PRIMARY`/`SECONDARY`/`DANGER`), urutan Batal–Simpan konsisten di modal | `src/components/ui/form.tsx`                                                            |
| Pola UI standar: dialog modal, disclosure (`aria-expanded`), tablist, menu akun kanan atas     | `modal.tsx`, `user-menu.tsx`, `AdminAuditWorkspace`                                     |
| Tema terang/gelap mengikuti preferensi                                                         | `src/components/theme/theme-toggle.tsx`                                                 |

Celah: HE-15, HE-20 (istilah tidak konsisten), HE-10 (kategori tidak bebas seperti dijanjikan), HE-23, HE-25, HE-29, HE-30.

## 4. Kemudahan Dipelajari (_Learnability_)

Sistem mendukung pengguna menemukan dan mempelajari fungsi dengan sedikit usaha.

| Bukti                                                                                                    | Lokasi                                                                           |
| -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| _Empty state_ yang memandu ("Buat siklus pertama, misalnya …", "Hubungi LPM agar akun Anda ditempatkan") | `EmptyState` di `cycle-manager.tsx`, `unit-manager.tsx`, `AuditeeAuditWorkspace` |
| Instruksi singkat di konteks ("Jawab **Ya** dengan bukti, atau **Tidak** dengan alasan.")                | `AuditeeAuditWorkspace`                                                          |
| Placeholder contoh nyata ("Siklus 2025/2026", "Apakah unit memiliki dokumen rencana kerja …")            | `CycleForm`, `InlineQuestionForm`                                                |
| Banner Ketua LPM menjelaskan ikon mahkota                                                                | `account-manager.tsx` (L193–200)                                                 |
| Panduan per peran tersedia                                                                               | [05-PANDUAN-PENGGUNA](../../05-PANDUAN-PENGGUNA.md)                              |

Celah: **HE-18** (panduan tidak dapat diakses dari aplikasi), HE-16, HE-17.

## 5. Keterkendalian (_Controllability_)

Pengguna dapat memulai dan mengendalikan arah & laju interaksi hingga tujuan tercapai.

| Bukti                                                                                              | Lokasi                                            |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Setiap modal dapat ditutup (tombol X, Esc, klik latar) kecuali dialog wajib persetujuan            | `modal.tsx` (`dismissible`), `consent-dialog.tsx` |
| Fokus dikembalikan ke pemicu setelah dialog/menu ditutup                                           | `use-focus-trap.ts`, `user-menu.tsx`              |
| Jawaban dapat diubah selama siklus terbuka; Ketua LPM dapat dicabut; siklus dapat diaktifkan ulang | `saveResponse`, `LpmHeadToggle`, `setActiveCycle` |
| Pengguna yang tidak setuju kebijakan privasi dapat keluar                                          | "Tidak setuju, keluar" (`consent-dialog.tsx`)     |
| Filter & pencarian (akun, verifikasi)                                                              | `account-manager.tsx`, `VerifikasiTab`            |
| Halaman galat dengan "Coba lagi" dan navigasi tetap tersedia                                       | `src/app/(dashboard)/error.tsx`, `error-view.tsx` |

Celah: **HE-08**, HE-13 (pemeliharaan tanpa keluar), HE-23 (tidak bisa memilih siklus di Audit), HE-24.

## 6. Ketahanan terhadap Kesalahan Penggunaan (_Use error robustness_)

Sistem membantu menghindari kesalahan; bila terjadi, kesalahan mudah dikenali dan diperbaiki.

| Bukti                                                                                                                                | Lokasi                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| Validasi klien berbahasa Indonesia + fokus otomatis ke field tidak valid pertama                                                     | `Field` `onInvalidCapture`                                              |
| Validasi server di setiap aksi (sumber kebenaran), pesan generik aman                                                                | `src/lib/validate.ts`, `src/lib/errors.ts` (diuji `validate`, `errors`) |
| Konfirmasi aksi destruktif dengan fokus awal pada **Batal** (Enter tidak langsung menghapus)                                         | `confirm-dialog.tsx`                                                    |
| Aturan bisnis mencegah keadaan tidak valid: satu siklus aktif, satu Kepala Unit, satu Ketua LPM, admin tidak dapat menghapus dirinya | AB-01, AB-12, AB-15, AB-25                                              |
| Pengisian ditolak di server bila siklus tertutup walau UI dimanipulasi                                                               | AB-03, `saveResponse`/`saveRtl`                                         |
| Berkas palsu ditolak (magic bytes), tautan non-http(s) ditolak                                                                       | `src/lib/upload.ts`, `isSafeHttpUrl` (diuji `upload`, `errors`)         |
| Tombol kirim dinonaktifkan selama proses (`useFormStatus`) mencegah kirim ganda                                                      | `SubmitButton`                                                          |

Celah: **HE-03, HE-04, HE-05, HE-11** (dampak penghapusan/aktivasi), HE-06, HE-07, HE-09, HE-12, HE-20, HE-24.

## 7. Keterlibatan Pengguna (_User engagement_)

Sistem menyajikan fungsi & informasi secara mengundang dan memotivasi, membangun kepercayaan.

| Bukti                                                                                                                           | Lokasi                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Desain visual konsisten (palet, kartu, ikon lucide), tema gelap/terang, animasi halus yang menghormati `prefers-reduced-motion` | `globals.css`, `motion-provider.tsx` (`MotionConfig reducedMotion="user"`) |
| Umpan balik progres yang memotivasi (bar progres, badge "Lengkap" hijau, grafik dashboard)                                      | `ProgressBar`, `AspectGroup`, `dashboard-charts.tsx`                       |
| Sapaan personal di topbar                                                                                                       | `topbar.tsx`                                                               |
| Transparansi privasi (ringkasan data diproses, hak subjek, unduh data saya) membangun kepercayaan                               | `consent-dialog.tsx`, `profil/page.tsx`, `/api/me/export`                  |
| Kinerja desktop baik (Lighthouse 96–97)                                                                                         | [09-DAFTAR-STANDAR §6](../../09-DAFTAR-STANDAR.md#6-performa-web)          |

Celah: kinerja **mobile 66–77** (TBT tinggi) mengurangi pengalaman auditee di ponsel; HE-26 (sapaan "Dr."); HE-31;
belum ada pengingat tenggat/notifikasi revisi.
