## Hal yang Sudah Baik (bukan temuan)

| Aspek                      | Bukti                                                                                                                                     |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Validasi inline Indonesia  | `Field` + `validationMessage()` mengganti gelembung bawaan peramban (`src/components/ui/form.tsx`)                                        |
| Umpan balik aksi           | `ActionFeedback` (`aria-live`, `role=alert/status`), `SubmitButton` dengan label proses "Menyimpan…"                                      |
| Konfirmasi aksi destruktif | `ConfirmAction` (`role="alertdialog"`, fokus awal pada **Batal**) untuk hapus unit/akun/standar/butir/dokumen, nonaktif siklus, purge log |
| Pesan login anti-enumerasi | Pesan generik (AB-19), diuji `tests/e2e/login.spec.ts`                                                                                    |
| Pesan galat SSO terpetakan | `SSO_ERROR_MESSAGES` (konfigurasi, ditolak, state, gagal, nonaktif, pemeliharaan, batas)                                                  |
| Navigasi                   | `aria-current="page"`, skip link, drawer mobile dengan focus trap & Esc                                                                   |
| Status siklus tertutup     | Banner "Periode pengisian ditutup" dan formulir baca-saja (`canEdit`)                                                                     |
| Halaman galat              | `not-found.tsx`, `error.tsx` (tombol Coba lagi, sidebar tetap tersedia), `/no-access`, pemeliharaan 503                                   |
